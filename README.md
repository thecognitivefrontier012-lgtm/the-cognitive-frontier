# THE COGNITIVE FRONTIER — Trợ lý AI Học tập SGK (Dự án KHKT)

Ứng dụng web hỗ trợ học tập thông minh cho môn **Tiếng Anh** và **Lịch Sử**, kết hợp **Gemini AI**, kỹ thuật truy xuất dữ liệu Sách giáo khoa (**RAG**) và thuật toán lặp lại ngắt quãng (**SuperMemo-2 / SM-2**).

## Hướng dẫn chạy dự án
1. Lưu đủ 3 file `index.html`, `style.css`, `app.js` vào cùng một thư mục.
2. Nhấp đúp vào file `index.html` để mở trực tiếp trên trình duyệt Chrome/Edge (không cần cài đặt server phức tạp).
3. *(Tùy chọn)* Vào tab **Cá nhân hóa**, dán **Gemini API Key** miễn phí từ Google AI Studio để AI trả lời trực tiếp mọi câu hỏi SGK.
